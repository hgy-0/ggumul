# 응원(Cheer) 기능 명세서

> 작성일: 2026-03-13
> 상태: 검토 대기

---

## 1. 개요

### 목적
친구에게 이모지 응원을 보내 소셜 동기부여를 강화한다. 현재 친구 기능은 목록만 표시되고 상호작용이 없어 "미완성" 상태이다.

### 핵심 원칙
- **가볍고 부담 없는 상호작용**: 텍스트 입력 없이 이모지 한 번 탭으로 응원 완료
- **받는 사람에게 동기부여**: 적절한 타이밍(앱 열 때, 목표 시작 전)에 응원을 표시
- **남용 방지 불필요**: 응원은 긍정적 행위이므로 횟수 제한 없음

---

## 2. 용어 정의

| 용어 | 설명 |
|------|------|
| 응원 (Cheer) | 친구에게 보내는 이모지 한 개. 비동기적으로 전달됨 |
| 읽지 않은 응원 (Unread Cheer) | 받은 사람이 아직 확인하지 않은 응원 |
| 응원 이모지 | 미리 정해진 5개: 👏 🔥 💪 🎉 ❤️ |

---

## 3. 함께 수정: 친구 이름 표시 개선

현재 닉네임이 없으면 `친구 1`, `친구 2`로 표시되는데, 순서 변경 시 혼란을 줄 수 있다.

### 변경 후 이름 우선순위

| 우선순위 | 조건 | 표시 이름 |
|----------|------|----------|
| 1 | 닉네임 설정함 | 닉네임 (예: "가영이") |
| 2 | 닉네임 없음 + 구글 로그인 | 구글 이름 (예: "김가영") |
| 3 | 닉네임 없음 + 비로그인 | "친구" (고정) |

### 수정 위치
- `firebaseFriends.ts`: `getFriends()`에서 `data.nickname || data.display_name || null` 으로 변경
- `FriendsList.tsx`: `friend.nickname || '친구'`로 변경 (인덱스 기반 제거)

## 4. 사용자 플로우

### 4-1. 응원 보내기 (친구 목록에서)

```
[친구 카드]
┌─────────────────────────────────┐
│  💪 가영이                       │
│  3일째 이어가는 중                │
│                                  │
│  [응원해주세요]     성공률 85%    │
└─────────────────────────────────┘

"응원해주세요" 버튼 클릭 시 → 이모지 선택 UI 등장:

┌─────────────────────────────────┐
│  💪 가영이                       │
│  3일째 이어가는 중                │
│                                  │
│  👏  🔥  💪  🎉  ❤️             │
└─────────────────────────────────┘

이모지 탭 → 전송 완료 → 피드백 표시:

┌─────────────────────────────────┐
│  💪 가영이                       │
│  3일째 이어가는 중                │
│                                  │
│  🔥 응원을 보냈어요!             │
└─────────────────────────────────┘

2초 후 원래 버튼으로 복귀.
```

- 같은 친구에게 여러 번 응원 가능 (횟수 제한 없음)
- 이모지 선택 영역 바깥 클릭 시 닫힘

### 4-2. 응원 받기 — 대시보드 배너

앱을 열었을 때 읽지 않은 응원이 있으면 대시보드 상단에 배너 표시:

```
[대시보드 상단]
┌─────────────────────────────────┐
│  👏 가영이님이 응원을 보냈어요!    │
│                         [확인]   │
└─────────────────────────────────┘
```

**여러 명이 보낸 경우:**
```
┌─────────────────────────────────┐
│  🎉 가영이님 외 2명이             │
│     응원을 보냈어요!              │
│                         [확인]   │
└─────────────────────────────────┘
```

- "확인" 클릭 → 모든 읽지 않은 응원을 읽음 처리 → 배너 사라짐
- 배너에 표시되는 이모지: 가장 최근 응원의 이모지 사용

### 4-3. 응원 받기 — 카운트다운 화면

목표 카운트다운을 시작할 때, 읽지 않은 응원이 있으면 타이머 위에 한 줄 표시:

```
[카운트다운 화면]

   "가영이님이 🔥을 보내며 응원하고 있어요!"

         ┌──────────┐
         │  04:32   │
         │          │
         └──────────┘

        [시작했어요!]
```

**여러 명인 경우:**
```
   "가영이님 외 2명이 응원하고 있어요! 🔥💪👏"
```

- 카운트다운 화면에서는 별도 확인 버튼 없이 표시만 함
- 대시보드 배너에서 확인하면 함께 사라짐

## 5. 데이터 모델

### 5-1. Firestore 컬렉션: `cheers`

```
cheers/{cheerId}
{
  from_device_id: string,     // 보낸 사람 ID
  to_device_id: string,       // 받는 사람 ID
  from_nickname: string,      // 보낸 사람 표시 이름 (스냅샷)
  emoji: string,              // 응원 이모지 ('👏', '🔥', '💪', '🎉', '❤️')
  read: boolean,              // 읽음 여부
  created_at: Timestamp,      // 생성 시각
}
```

**문서 ID 규칙:** `{from_device_id}_{to_device_id}_{timestamp}`

### 5-2. TypeScript 타입

```typescript
export interface Cheer {
  id: string;
  from_device_id: string;
  from_nickname: string | null;
  emoji: string;
  created_at: string;
}
```

### 5-3. 필요한 Firestore 복합 인덱스

| 컬렉션 | 필드 | 용도 |
|--------|------|------|
| `cheers` | `to_device_id` ASC, `read` ASC, `created_at` DESC | 읽지 않은 응원 조회 |

## 6. API 설계

### 6-1. 응원 보내기
```
POST (Firebase): cheers 컬렉션에 문서 생성
입력: friendDeviceId, emoji
```

### 6-2. 읽지 않은 응원 조회
```
GET (Firebase): cheers에서 to_device_id == 나, read == false 쿼리
출력: Cheer[] (최대 20개, 최신순)
```

### 6-3. 응원 읽음 처리
```
BATCH UPDATE (Firebase): 전달된 cheer ID들의 read를 true로 변경
입력: cheerIds: string[]
```

## 8. Firestore 보안 규칙 추가

```
match /cheers/{cheerId} {
  allow read: if true;
  allow write: if true;
}
```

> MVP 단계에서는 open. 추후 인증 기반으로 제한 가능:
> - read: `resource.data.to_device_id == 본인` 또는 `resource.data.from_device_id == 본인`
> - create: `request.auth != null`

## 9. 엣지 케이스

| 케이스 | 처리 방식 |
|--------|----------|
| Firebase 미설정 상태 | 응원 버튼 숨김 또는 비활성화 |
| 같은 친구에게 연속 응원 | 허용. 각각 별도 문서로 저장 |
| 응원 100개 이상 쌓임 | 쿼리에 `limit(20)` 적용. 오래된 것은 자연스럽게 무시 |
| 친구 삭제 후 응원 | 응원 문서는 남아있으나, 친구 목록에 없으므로 표시 안 됨. 별도 삭제 불필요 |
| 닉네임 없는 친구가 응원 보냄 | `from_nickname`에 구글 이름 또는 '친구' 저장 (스냅샷 방식) |
| 오프라인 상태에서 응원 | Firestore 오프라인 캐시로 자동 큐잉. 온라인 복귀 시 전송 |
